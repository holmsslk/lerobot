# OpenArm

[OpenArm](https://openarm.dev) 是一款开源的 7 自由度类人机械臂，面向具身智能研究与实际部署。

如果你想获取 OpenArm，无论是整机购买还是自行组装，也希望加入它的全球社区，可以前往 [openarm.dev](https://openarm.dev) 查看全球经过认证和验证的制造商。

## 有什么特别之处？

- **接近人体尺度的设计**：OpenArm 采用接近人类手臂的比例，整体尺寸参考约 160-165cm 身高的人体。这在可达范围和惯性控制之间取得了良好的平衡，便于实现安全、灵敏的操作。

- **安全优先的架构**：采用 QDD 可回驱电机，并具有较高顺应性。OpenArm 在强调安全人机交互的同时，也保留了现实任务中可用的负载能力（单臂峰值 6.0kg，额定 4.1kg）。

- **强调耐用性**：关键结构件使用铝合金和不锈钢制造，适合高频数据采集和持续科研使用。

- **充分开放且可自行构建**：从 CNC 零件、3D 打印外壳到电气接线，所有部件都可以由个人研究者或实验室自行采购和搭建，并提供完整制造资料。

- **实用且成本较低**：完整双臂系统约 6500 美元，以远低于传统人形机器人平台的成本提供研究级能力。

## 平台要求

<Tip warning={true}>
  **仅支持 Linux**：OpenArm 当前只能在 Linux 上工作。其使用的 CAN 总线 USB 适配器没有 macOS 驱动，也尚未在 Windows 上验证。
</Tip>

## 安全指南

在操作 OpenArm 之前，请先阅读[官方安全指南](https://docs.openarm.dev/getting-started/safety-guide)。重点包括：

- **牢固安装**：使用螺丝或夹具将机械臂固定在平整、稳定的表面上
- **保持安全距离**：运行时不要让身体部位或其他物体进入机械臂运动范围
- **佩戴防护装备**：始终佩戴护目镜，必要时使用额外个人防护装备
- **不要超载**：不要超过规定负载（单臂峰值 6.0kg / 额定 4.1kg）
- **熟悉急停**：清楚紧急停止装置的位置和操作方式
- **定期检查**：检查螺丝是否松动、机械限位是否损坏、是否存在异常噪音，以及线缆是否破损

## CAN 总线配置

OpenArm 通过 CAN 总线与 Damiao 电机通信。当你将 CAN 总线 USB 适配器接入 Linux 主机后，请按照 [Damiao 电机与 CAN 总线指南](./damiao) 配置接口。

快速配置：

```bash
# 配置 CAN 接口
lerobot-setup-can --mode=setup --interfaces=can0,can1

# 测试电机通信
lerobot-setup-can --mode=test --interfaces=can0,can1
```

## 安装 LeRobot 🤗

先按照[安装指南](./installation)安装 LeRobot，然后安装 Damiao 电机支持：

```bash
pip install -e ".[damiao]"
```

## 使用方法

### Follower Arm（从臂 / 机器人本体）

<hfoptions id="follower">
<hfoption id="Command">

```bash
lerobot-calibrate \
    --robot.type=openarm_follower \
    --robot.port=can0 \
    --robot.side=right \
    --robot.id=my_openarm_follower
```

</hfoption>
<hfoption id="API example">

```python
from lerobot.robots.openarm_follower import OpenArmFollower, OpenArmFollowerConfig

config = OpenArmFollowerConfig(
    port="can0",
    side="right",  # 左臂则填 "left"
    id="my_openarm_follower",
)

follower = OpenArmFollower(config)
follower.connect()

# 读取当前状态
obs = follower.get_observation()
print(obs)

# 发送动作（单位：度）
action = {
    "joint_1.pos": 0.0,
    "joint_2.pos": 0.0,
    "joint_3.pos": 0.0,
    "joint_4.pos": 45.0,
    "joint_5.pos": 0.0,
    "joint_6.pos": 0.0,
    "joint_7.pos": 0.0,
    "gripper.pos": 0.0,
}
follower.send_action(action)

follower.disconnect()
```

</hfoption>
</hfoptions>

### Leader Arm（主控臂 / 遥操作器）

Leader arm 用于遥操作，也就是由人手动带动它，再去控制 follower arm。

<hfoptions id="leader">
<hfoption id="Command">

```bash
lerobot-calibrate \
    --teleop.type=openarm_leader \
    --teleop.port=can1 \
    --teleop.id=my_openarm_leader
```

</hfoption>
<hfoption id="API example">

```python
from lerobot.teleoperators.openarm_leader import OpenArmLeader, OpenArmLeaderConfig

config = OpenArmLeaderConfig(
    port="can1",
    id="my_openarm_leader",
    manual_control=True,  # 关闭力矩，方便手动拖动
)

leader = OpenArmLeader(config)
leader.connect()

# 读取当前位置，并作为动作发送给 follower
action = leader.get_action()
print(action)

leader.disconnect()
```

</hfoption>
</hfoptions>

### 遥操作

如果要用 leader-follower 方式遥操作单臂 OpenArm：

```bash
lerobot-teleoperate \
    --robot.type=openarm_follower \
    --robot.port=can0 \
    --robot.side=right \
    --robot.id=my_follower \
    --teleop.type=openarm_leader \
    --teleop.port=can1 \
    --teleop.id=my_leader
```

### 双臂遥操作

如果要进行双臂 OpenArm 遥操作，也就是两个 leader 对应两个 follower：

```bash
lerobot-teleoperate \
    --robot.type=bi_openarm_follower \
    --robot.left_arm_config.port=can0 \
    --robot.left_arm_config.side=left \
    --robot.right_arm_config.port=can1 \
    --robot.right_arm_config.side=right \
    --robot.id=my_bimanual_follower \
    --teleop.type=bi_openarm_leader \
    --teleop.left_arm_config.port=can2 \
    --teleop.right_arm_config.port=can3 \
    --teleop.id=my_bimanual_leader
```

### 录制数据

如果要在遥操作过程中录制数据集：

```bash
lerobot-record \
    --robot.type=openarm_follower \
    --robot.port=can0 \
    --robot.side=right \
    --robot.id=my_follower \
    --teleop.type=openarm_leader \
    --teleop.port=can1 \
    --teleop.id=my_leader \
    --repo-id=my_hf_username/my_openarm_dataset \
    --fps=30 \
    --num-episodes=10
```

## 配置项说明

### Follower 配置

| 参数 | 默认值 | 说明 |
| --------------------- | --------- | ---------------------------------------------------------- |
| `port` | - | CAN 接口名，例如 `can0` |
| `side` | `None` | 手臂侧别：`"left"`、`"right"`，或 `None`（表示使用自定义限位） |
| `use_can_fd` | `True` | 是否启用 CAN FD 以获得更高带宽 |
| `can_bitrate` | `1000000` | CAN 标称速率（1 Mbps） |
| `can_data_bitrate` | `5000000` | CAN FD 数据速率（5 Mbps） |
| `max_relative_target` | `None` | 相对目标位置的安全限制 |
| `position_kp` | Per-joint | 位置控制的比例增益 |
| `position_kd` | Per-joint | 位置控制的微分增益 |

### Leader 配置

| 参数 | 默认值 | 说明 |
| ------------------ | --------- | ----------------------------------- |
| `port` | - | CAN 接口名，例如 `can1` |
| `manual_control` | `True` | 关闭力矩，便于人工拖动 |
| `use_can_fd` | `True` | 是否启用 CAN FD |
| `can_bitrate` | `1000000` | CAN 标称速率（1 Mbps） |
| `can_data_bitrate` | `5000000` | CAN FD 数据速率（5 Mbps） |

## 电机配置

OpenArm 默认使用 Damiao 电机，配置如下：

| 关节 | 电机型号 | 发送 ID | 接收 ID |
| --------------------------- | ---------- | ------- | ------- |
| `joint_1`（肩部平转） | DM8009 | 0x01 | 0x11 |
| `joint_2`（肩部抬升） | DM8009 | 0x02 | 0x12 |
| `joint_3`（肩部旋转） | DM4340 | 0x03 | 0x13 |
| `joint_4`（肘部弯曲） | DM4340 | 0x04 | 0x14 |
| `joint_5`（腕部滚转） | DM4310 | 0x05 | 0x15 |
| `joint_6`（腕部俯仰） | DM4310 | 0x06 | 0x16 |
| `joint_7`（腕部旋转） | DM4310 | 0x07 | 0x17 |
| `gripper`（夹爪） | DM4310 | 0x08 | 0x18 |

## 故障排查

### 电机无响应

1. 检查电源连接
2. 检查 CAN 接线是否正确（CAN-H、CAN-L、GND）
3. 运行诊断命令：`lerobot-setup-can --mode=test --interfaces=can0`
4. 参考 [Damiao 故障排查指南](./damiao#troubleshooting) 获取更多细节

### 找不到 CAN 接口

确认 CAN 接口是否已经正确配置：

```bash
ip link show can0
```
